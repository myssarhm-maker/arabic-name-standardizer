# Arabic Name Standardizer

A project for standardizing Arabic names into one approved English spelling.

## Version 0.1

This first version provides:
- A Python canonical-name engine.
- A starter Arabic-to-English canonical dictionary.
- Tests.
- A Chrome Extension popup for converting Arabic names.
- A clean structure for future Excel/Office integration.

## Examples

- محمد -> Muhammad
- محمد علي -> Muhammad Ali
- عبدالرحمن -> Abdulrahman
- عبد الرحمن -> Abdulrahman

## Important

The dictionary is intentionally editable. The project should eventually support an institutional Iraqi naming standard, including approved spellings and compound names.
